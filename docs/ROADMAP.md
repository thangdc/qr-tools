# Roadmap

## Phase 0 — Source of Truth
- Product documentation
- Architecture boundaries
- ADRs
- AI development context

## Phase 1 — Core
- Workflow contracts
- Validation
- Mapping
- QR identity abstraction
- Reference workflow: Equipment Maintenance

## Phase 2 — Dynamic QR
- Signed/versioned QR protocol
- Resolve QR to workflow/record
- Revocation
- Basic scan/action flow

## Phase 3 — API
- Versioned public API
- API authentication
- Rate limiting/usage policy
- Customer-owned UI support

## Phase 4 — SDK
- JavaScript/TypeScript SDK
- Browser-safe integration
- Examples/documentation

## Phase 5 — Connectors
- Excel/CSV
- Google Sheets
- REST API
- Webhooks
- Additional integrations based on demand

## Non-goal

Do not build every connector before the core workflow has been proven with real users.
