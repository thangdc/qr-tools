# Developer Dashboard Roadmap

## Phase 4.1 — Contract

This phase defines:

- domain ownership
- navigation
- API key lifecycle
- usage scope
- test console scope
- security boundaries

No implementation or new public API endpoint is included.

## Phase 4.2 — Authentication

Implement developer sign-in/session management for `client.thangdc.com`.

## Phase 4.3 — API key management

Implement create, one-time reveal, list, revoke, and rotate.

## Phase 4.4 — Usage

Expose aggregate request/error/rate-limit information.

## Phase 4.5 — Test console

Add scan and action execution against the existing public API contract.

## Phase 4.6 — SDK

Only after the dashboard and API contract are stable, publish SDKs.

The SDK is a separate phase and must not expand the API contract by implication.
