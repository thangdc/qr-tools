# Product

## Vision

QR Tools helps businesses turn QR codes into practical workflows, not merely static links.

## Positioning

QR Tools is a QR Workflow Infrastructure Platform with:
- No-code workflows for normal users
- Low-code SDK/embed options for existing websites
- API-first integration for developers and businesses

## Core Value

A customer can bring data from an existing source, validate and map it, generate QR identities, and define what happens when those QR codes are scanned.

## Example

Equipment data:
- Asset ID
- Name
- Location
- Maintenance date

Workflow:
Data source → validate → map → generate QR → print → scan → resolve record → show/custom action → send result to API/Sheet.

## Target Users

- Small businesses
- Property/apartment management
- Maintenance teams
- Schools and attendance use cases
- Inventory/asset management
- Developers integrating QR into an existing system

## Product Modes

### Hosted UI
Users configure and execute workflows in QR Tools.

### SDK
Customers embed QR functionality into their own web application.

### API
Customers own the UI and call QR Tools for QR/workflow infrastructure.

## Product Boundary

QR Tools should own the QR/workflow infrastructure. Customers may own their business UI, business database, and surrounding application.

## Non-goals

- Generic automation platform competing with Zapier
- Arbitrary user scripting as a default workflow mechanism
- Rebuilding a customer's entire business application
